# 🧭 真一盲派排盘口径

当前日期时间排盘默认采用：

- **0点换日**：23:00–24:00 为夜子时；00:00–01:00 为早子时
- **早晚子时分排**：夜子时保留本日日柱，并按对应规则纳时干
- **立春分年**
- **节令分月**
- **精确节气时刻**
- **盲派虚岁起运**
- **年命纳音交运**
- **大运干支五年分运**

详细规则：

[`docs/ALGORITHM_DECISIONS.md`](docs/ALGORITHM_DECISIONS.md)

# 🌞 真太阳时

真太阳时默认开启，可主动关闭。

系统根据：

- 出生地经度
- 均时差
- 民用时间

计算有效排盘时间，并直接用于：

- 四柱计算
- 跨时辰判断
- 跨日判断

同时记录：

- `time_basis`
- `effective_time`
