**真一八字排盘**是一套以**真一盲派排盘口径与做功体系**为核心、面向真实命理工作场景开发的开源排盘系统。

真一八字排盘，专注盲派排盘与做功判断，把流星赶月、节气定月、早子夜子、真太阳时、起运大运和命局做功，完整整理成现代化开源系统。
排盘更准确，规则更完整，判断更专业，结果更清晰。

> **传统术数很古老，但它的工具不应该停留在过去。**

## ✨ 核心能力

### 🧭 四柱直排

支持已知八字的用户直接录入年柱、月柱、日柱、时柱：

- 每柱从标准 60 甲子中选择，避免无效天干地支组合
- 自动校验五虎遁与五鼠遁关系
- 不强行反推出生日期、出生地点或真太阳时
- 出生年份与起运年龄为可选信息；未填写时仅生成大运顺序，不虚构具体流年

### 🧭 真一盲派排盘口径

当前日期时间排盘默认采用以下规则：

- **0 点换日**：23:00–24:00 为夜子时，日柱仍属本日；00:00–01:00 为早子时
- **早晚子时分排**：夜子时保留本日日柱，并按夜子时规则重新纳时干
- **立春分年、节令分月**：交节边界继续使用精确节气时刻
- **盲派虚岁起运**：按生日到顺/逆最近节令的日数除以三，余一舍、余二进，1–10 虚岁
- **大运干支分运**：每运十年，前五年运干、后五年运支
- **年命纳音交运**：五年一交，十年两交；v1.5 已把交运口诀落实为真实交运日期与时辰窗口

具体规则、来源取舍与资料异文说明见 [`docs/ALGORITHM_DECISIONS.md`](docs/ALGORITHM_DECISIONS.md)。

### 🧠 第一主功状态重演

v1.9 在原有做功主线、岁运身份和关系语义之上增加 **State Replay**：

> 原局第一主功 → 大运是否真正承接/改变 → 流年如何引动 → 流月只做细化定位

系统不会因为某个流年单独出现合冲，就重新创造一件原局不存在的大事。根气也不再用“所有柱相加”的分数，而是区分坐下直接根、长生/墓库/余气得气与其它柱外部支持。


### 🌞 真太阳时排盘

真太阳时继续保留，并且在日期时间排盘中**默认开启**；用户可以主动关闭。

- 开启：根据出生地经度与均时差校正时间，并使用校正后的时间进入四柱计算
- 关闭：直接按用户输入的民用时间排盘，出生地点改为选填
- 无论是否开启，结果对象都会明确记录 `time_basis` 与 `effective_time`，避免混淆本盘实际采用的时间口径

支持出生地经度修正、均时差修正、真太阳时实时预览、跨时辰与跨日处理。

> 真太阳时默认开启是本项目的产品/工程选择，不宣称为真一盲派原法中的强制规则。

### 🧭 专业八字排盘

当前开源版本已实现：

- 公历 / 农历 / 闰月排盘
- 二十四节气
- 年柱 / 月柱 / 日柱 / 时柱
- 真太阳时
- 十神
- 藏干 / 副星
- 十二长生
- 纳音
- 旬空
- 胎元 / 命宫 / 身宫 / 胎息
- 盲派虚岁起运 / 纳音交运（真实交运日期与时辰窗口）
- 12 步大运（前五年运干 / 后五年运支，按交运窗口真实切换）
- 120 流年（交运年保留前后阶段）
- 盲派四柱大限背景
- 盲派岁运身份解析（同字 / 固定禄 / 固定原身 / 藏干显现）
- 盲派应期关系语义（冲动 / 冲去 / 冲墓候选；合动 / 合留 / 合绊候选）
- 动态墓库状态快照（历史事实与当前 active state 分离）
- 未来年份仅列应期候选理由，不按冲合数量打“强/中/静”分
- 大运阶段门与反客为主应期候选
- 墓库状态机（真实入墓 / 冲墓待仲裁，不机械开库）
- 小运（辅助参考，不进入当前做功主仲裁）
- 五行统计与评分
- 日主强弱参考
- 神煞系统

结果页按照实际使用场景划分为：

**基本信息 / 基本命盘 / 专业岁运 / 盲派判盘**

专业岁运页已升级为“盲派岁运工作台”：

- **大运 → 流年 → 流月** 三级联动；
- 大运明确显示十年整柱、前五年运干、后五年运支及当前主事部分；
- 流年按立春切换，流月按十二节令切换，月干按五虎遁生成；
- 流月按所选年份即时加载，不把 120×12 个流月常驻主命盘数据；
- 选择历史 / 未来流月时，会按该月节令起点调用同一 v1.9 判盘引擎重算 State Replay，不拿当前月份状态替代；
- 第一主功、阶段门、身份到位、根气变化、墓库状态、组合结构等已进入专业页可视化。

流月仍严格属于**细化定位层**：不得单独创造原局不存在的重大事件。若某流月内恰好包含大运交接节点，页面会提示该月前后状态不同。

详细交互与边界口径见 [`docs/UI_V2.md`](docs/UI_V2.md)。

## 👤 关于真一

真一不是从“做一个命理网站”开始的。

项目背后是长期的线下命理工作与传统师承经历。我们真正关心的，从来不只是软件能不能排出八个字，而是**传统方法如何在今天仍然能够被准确地使用，专业经验如何通过现代技术转化成更稳定、更易用的工具。**

师门中的很多方法，本来依赖口传心授、长期实践和大量案例才能逐渐掌握。技术并不能替代这些经验，但它可以把基础计算、资料组织、规则调用和工作流程做得更好，让专业人士把注意力放回真正重要的判断上。

所以真一选择把**基础排盘能力开源**。

排盘可以透明，算法可以讨论，工程可以共同完善；而真正需要长期实践形成的理法、经验和判断体系，我们仍然保持应有的专业边界。

## 💡 为什么开源？

我们愿意把基础排盘开放出来，是因为排盘本身应该尽可能透明。

开发者可以阅读实现，命理从业者可以核对规则，不同体系之间也可以基于清楚的代码讨论差异，而不是永远依赖无法解释的黑箱结果。

**开源基础能力，保留专业方法；让传统术数与现代工程各自发挥真正的价值。**
