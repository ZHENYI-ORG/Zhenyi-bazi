## 真太阳时跨日

专项样本验证真太阳时修正不只是展示字段，而是实际进入四柱计算：

- 北京时间接近午夜、经度偏西：修正后可能进入前一日
- 北京时间接近 24 点、经度偏东：修正后可能进入后一日

两种方向均有回归向量覆盖。

## 测试边界说明

“PHP 与 TypeScript 一致”证明的是迁移行为一致，不是对所有命理流派作唯一正确性的宣称。

如果你发现规则口径差异，请尽量区分：

1. 软件工程 Bug；
2. 历法实现差异；
3. 真太阳时取值差异；
4. 换日 / 节气边界口径差异；
5. 命理门派理论差异。
