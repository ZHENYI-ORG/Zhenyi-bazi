# 测试与回归验证

## 当前结论

v1.9.0 的回归基准已经从“旧 PHP 行为兼容”升级为“盲派规则 + 历法底座 + 做功判断”的组合验证。

旧 PHP / TypeScript 对拍仍可作为历法迁移历史资料参考，但**不再作为起运、交运、子时边界等盲派规则的最终裁决标准**。这些规则以 `docs/ALGORITHM_DECISIONS.md` 记录的当前口径为准。

## v1.9.0 关键盲派回归

固定验证：

- 真太阳时默认开启，关闭后可不提供出生地点 / 经度
- 海外西经 + IANA 时区真太阳时
- 夏令时 / DST 跳时与重复民用时间边界
- 流年按精确立春切换
- 流月按十二节令切换，并只作为细化应期
- 关闭真太阳时时，`time_basis = civil`，输入时间直接进入四柱计算
- 0 点换日
- 23:00–24:00 夜子时保持本日日柱
- 00:00–01:00 早子时进入新日
- 夜子时独立纳时干
- 四柱直排允许合法夜子时时柱
- 盲派三日一岁起运：余一舍、余二进，1–10 虚岁
- 大运前五年运干、后五年运支
- 流年输出当前 `dayun_phase` / `active_dayun_component`
- 交运日期与时辰窗口真实参与运干/运支切换
- 交运“前三天 / 后九天”按传统包含式虚数计日：节气当日计入，历日偏移分别为 -2 / +8
- 交运年记录切换前/后的运组件
- 年柱纳音五行交运规则
- 四柱直排填写出生年份后，可输出纳音交运规则

### 固定子时案例

```text
2010-12-09 00:30 → 庚寅 戊子 癸巳 壬子（早子）
2010-12-09 23:30 → 庚寅 戊子 癸巳 甲子（夜子）
2010-12-10 00:30 → 庚寅 戊子 甲午 甲子（早子）
```

### 固定起运案例

```text
男命：2005-03-15 10:00
年柱：乙酉（阴年男命逆排）
向前取惊蛰，日期相差 10 天
10 ÷ 3 = 3 余 1
=> 3 虚岁起运
```

该命年命纳音为水，交运规则输出：

```text
水命：冬至前3日亥时交运；五年一交，十年两交
传统计数：包含冬至当日；若冬至公历日为 12-22，则“前三日”交运日为 12-20
```

## 历史 PHP 对拍说明

早期 TypeScript 迁移曾使用 300 组 PHP → TypeScript 全字段对拍，以及 1901–2099 公农历往返扫描。这些测试证明旧版迁移和历法实现的稳定性，但当前 v1.9.0 已在此基础上有意修改：

- 23:00–24:00 日界处理
- 起运口径
- 交运口径
- 大运干支分阶段

因此上述字段**不应再要求与旧 PHP 历史输出完全一致**。

如果出现差异，应先区分：

1. 软件工程 Bug；
2. 历法实现差异；
3. 真太阳时开关 / 时间口径差异；
4. 0 点换日与早晚子时规则差异；
5. 起运 / 交运门派规则差异；
6. 做功与岁运解释层差异。

## v1.9 新增专项回归

新增至少以下确定性测试：

- 坐下直接根与其它柱外援分离，不再用统一 `root_score`；
- 坐禄、坐墓、坐余气分别落入不同 `capacity_status`；
- 仅大运普通生克时 `stage_gate=context_only`，不得单独打开重大应期门；
- 原局合逢大运冲时，State Replay 只输出“原合被解候选”，不自动写反局/完成；
- 流年见固定禄可增强当前根气承载，但不会回写原局 `roots`；
- 根气按大运 / 流年 / 流月分别快照，后来的流年不得反写前面的大运根气状态；
- 三合 / 三会 / 三刑只在首次形成的时间层标记 `newly_formed=true`，后续阶段不得重复制造“新成局”。

当前判盘专项：**30/30**；原书结构基准：**8/8**；排盘/时间链：**49/49**。
