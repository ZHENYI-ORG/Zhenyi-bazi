# 地区数据来源与版本说明

## 基础数据

项目的省 / 市 / 区县三级行政区划及部分经纬度数据基于开源项目：

- **AreaCity-JsSpider-StatsGov**
- 上游仓库：`xiangyuecn/AreaCity-JsSpider-StatsGov`
- 上游协议：MIT License
- 本项目采用的基础版本：`2025.251231.260403`
- 上游版本更新时间：2026-04-03

上游项目综合国家地名信息库、腾讯地图、高德地图等公开行政区划数据进行整理。

## 本项目处理

本项目将适合排盘出生地选择的三级数据转换并打包到：

```text
public/assets/china-regions.js
```

运行时不请求百度 / 高德等地图接口，也不需要 API Key。

出生地经度主要用于真太阳时计算。经纬度优先采用区县代表坐标；个别新设或暂时无法精确匹配的地区可能使用公开中心坐标、政府驻地附近坐标或上级中心点作为回退。

## 精度说明

区县代表经度适合一般排盘使用，但它不等同于具体出生医院、村镇或街道的精确经度。

对于恰好处于时辰交界附近、且对真太阳时精度要求极高的场景，建议调用方允许用户使用更精确的实际出生地经度覆盖默认区县经度。
