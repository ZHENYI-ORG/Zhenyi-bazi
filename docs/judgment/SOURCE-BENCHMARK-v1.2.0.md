# 真一判盘引擎 v1.2.0 — 原书命例一致性基准

## 这份测试证明什么

它验证的是：

> **程序是否能够复现当前已经冻结的盲派理法结构。**

它不等于“真实人生预测准确率”，也不等于传统命理已经得到现代科学验证。

因此本项目把测试分成三层：

1. **程序回归**：事实计算有没有写错；
2. **原书一致性**：第一主线是否与选定理论资料的明确分析一致；
3. **真实命例金标准**：未来用已知现实反馈的命盘，由人工标注主功、归属和岁运，再统计一致率。

目前已经完成前两层的一部分。

## v1.2.0 首批 8 个原书金标准

数据文件：

```text
tests/judgment-source-benchmark-vectors.json
```

执行：

```bash
npm run test:judgment:source
```

当前结果：

```text
8 / 8 passed
```

### 01 申子辰党局中的食伤制杀

四柱：

```text
壬寅 戊申 戊子 丙辰
```

资料主线：日干无功，转看日支；子为三合中神，申食神冲制寅七杀。

引擎要求：

```text
第一主线 = 食伤制杀
方向 = forward
状态 = effective
```

### 02 “看起来有克”但原书判无功

```text
癸卯 庚申 甲寅 辛未
```

资料明确指出日干无功，日支被七杀冲，寅入未墓也没有取得能力，整体没有有效功。

这个例子专门防止程序犯以下错误：

```text
寅木克未土
→ 比劫制财
→ 自动升级第一主线
```

v1.2.0 已改为：普通邻支五行相克若没有真实制法、党势或其他闭环，只保留条件候选，不升第一主线。

### 03 做功不足时必须转象法

```text
癸卯 丁巳 丁巳 乙巳
```

资料明确说从做功角度没有足够作用，需从象理解。

引擎必须进入：

```text
xiang_fallback
```

不能为了“每盘都必须有格局”而硬造做功。

### 04 正向做功

```text
丁巳 丙午 癸亥 壬子
```

资料：日时主位比劫为体，子午、巳亥冲，主位之体取年月财。

引擎：

```text
比劫制财
forward
```

### 05 反向做功

```text
甲子 丙子 辛巳 丙申
```

资料：年月子水食神与申成党，宾位之体制主位巳火官。

v1.2.0 新增独立字段：

```text
gongDirection = reverse
```

注意：**反向做功 ≠ 反局。**

这是两个完全不同的概念，程序已经拆开。

### 06 连续制局

```text
辛卯 丁酉 庚午 丙子
```

原书先明确子水伤官制午火官，再继续分析后续多层制局。

当前第一主线：

```text
食伤制官
```

后续版本继续扩展“金字塔式多层功”的图结构表达。

### 07 火土成势制财

```text
丁亥 庚戌 己巳 庚午
```

原书明确以“火与燥土之势”解释整个命局，并通过戌克亥、巳冲亥、丁亥自合等共同作用制亥水。

旧版单元素气势算法会漏掉这种结构。

v1.2.0 已支持：

```text
火 → 土
```

这种相生党势识别。

当前输出：

```text
火、土成势制财
forward
```

### 08 财星做功制印

```text
壬寅 戊申 丙申 壬辰
```

原书重点：申辰一党，申去制寅，财星做功。

当前程序能把主线落到：

```text
...成势制印
```

并识别为有效、正向作用。

# v1.2.0 相比 v1.1.0 的关键修复

## 1. 不再让所有地支任意做功

旧算法会对所有地支做五行生克扫描。

这会导致：

```text
只要木旁边有土
→ 就容易出现比劫制财
```

现在普通支间五行关系只在相邻位置建立；即使相邻，单独普通相克也默认只能进入 `conditional`，不会自动成为第一主线。

## 2. 冲本身可以成为真实制用动作

原书大量做功来自：

```text
冲制
穿制
合制
刑制
```

v1.2.0 开始把“冲”从纯关系展示升级为可参与做功的真实动作，并根据：

- 五行方向；
- 气势；
- 宾主；
- 十神对象；

判断谁制谁。

## 3. 完整党局影响宾主归属

例如日支落在完整三合中神时，年月中的党内成员不能仍机械当作“纯外人”。

当前只在**完整三合/三会且包含日支**时做上下文权重提升，不改变原始柱位事实。

## 4. 支持相生党势

新增：

```text
火土
金水
木火
水木
土金
```

等相生党势候选。

必须同时满足实体分数和相对优势门槛，不能只凭两个五行出现就叫成势。

## 5. 正向 / 反向做功正式独立

新增：

```ts
gongDirection:
  | "forward"
  | "reverse"
  | "internal"
  | "external"
  | "mixed"
```

它与：

```text
正局 / 反局
```

完全分开。

## 6. 第一主线只允许 effective

`conditional` 现在可以留在候选路径里，但不能被包装为正式第一主线。

当全盘只有条件候选时：

```text
宁可降级象法 / 意向未闭环
也不硬断一个主功
```

# 目前还不能说“很准”的原因

8 个原书命例通过只能说明：

> 这 8 个明确结构已经能够被程序稳定复现。

下一阶段必须扩展到：

```text
50~100 个原书明确命例
+
200 个内部人工标注真实命盘
+
100 个冻结验证盘
```

并统计：

- 第一主线一致率；
- 功归属一致率；
- 正/反局一致率；
- 虚构关系率；
- 过断率；
- 岁运触发一致率。

在这之前，产品可以说：

> **已经具备真正的“判盘引擎”雏形。**

但不应该宣传：

> “准确率 90% / 95% / 99%”。

目前没有这样的真实验证数据。
