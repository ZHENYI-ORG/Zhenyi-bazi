# 判盘页 UI 重构 v1.3.0

本次只重构「判盘」页面的信息层级和交互，不修改盲派判盘引擎的判断逻辑。

## 目标

旧版判盘页虽然信息完整，但阅读顺序仍偏“工程输出”：用户需要先看关系图，再自己理解成果归属、正反局和岁运。v1.3.0 改成「先结论 → 再关键结果 → 再路径 → 最后依据」。

## 新的信息层级

1. **命局总览**：保留“这张盘到底在做什么”，下方直接显示四柱关系，并用金色/灰色区分做功主体和目标/承接。
2. **核心结论**：第一主线名称与状态位于最显眼位置。
3. **一句话判断**：新增“断”标识，把引擎 summary 作为主结论阅读。
4. **四个关键结果**：怎么做、最后归谁、命局配合、当前阶段；移动端使用 2×2，首屏即可读到。
5. **做功路径**：降为第二层信息，回答“谁在做 → 怎么做 → 对谁做”。
6. **什么时候会动**：未来五年触发单独成卡；手机改为横向滑动，避免五个年份被压缩得过小。
7. **盘面探索**：默认折叠。点击四柱任一干支会自动展开，查看身份、根气、宾主、来源、意向和关系。
8. **为什么这样判**：证据链默认折叠，普通用户不被技术信息淹没；需要核对时再展开。

## 视觉调整

- 延续现有白色 / 暖灰 / 香槟金体系，不引入新的黑色大面积面板。
- 卡片边框、阴影更轻，核心结论使用暖灰底而非高饱和提示色。
- 四柱高亮增加顶部细线和图例，不只靠背景色表达角色。
- 手机端核心结果改为 2×2，PC 保持紧凑双列。
- 字体设置入口移动，避免和“保存 / 重排”操作重叠。
