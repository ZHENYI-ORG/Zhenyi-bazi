# 真一盲派做功引擎 — 资料研究与规则准入矩阵 v1.0

## 一、资料优先级

### S级（核心原理优先）
- 内部核心资料 A
- 内部核心资料 B
- 内部核心资料 C中有明确方法解释、并可与其他核心材料互证的章节

### A级（系统资料）
- 内部系统资料 A
- 盲派初级/中级/高级班系统资料
- 内部系统资料中有明确条件与案例的方法

### B级（课堂/学生整理）
- 内部研究笔记 B
- 广州/太原笔记
- 单次课堂断语、条件不完整的记录

### C级（隔离）
- 无法确认来源的网络口诀
- 与核心材料冲突且不能解释的整理稿
- 只有案例结果，没有可迁移条件的“铁口”

---

## 二、规则登记状态

- `verified`：原理、成立条件、反证和至少一个完整案例链基本齐全。
- `school_specific`：明确属于盲派/项目口径，但不是通用关系，必须白名单。
- `case_only`：目前只有案例归纳，不能自动直断。
- `disputed`：不同材料冲突，暂不生产化。

| 复合结构 | verified | 需要图路径 |

| 气势/党势 | verified | 不能只按数量 |
| 十神意向改变 | verified | 必须有 Intent 层 |
| 正局/反局 | verified | 依赖意向与气势 |
| 冲动/冲开/冲去/冲破 | verified | 需层级与条件 |
| 合留/合绊/合动/合去等 | verified | 需上下文 |
| 固定禄/原身互通 | school_specific | 白名单化 |

## 五、绝对禁止

- 只凭“出现某十神”就输出真实事件。
- 只凭“冲”就断坏。
- 只凭“合”就断好。
- 只凭“见墓”就说入墓。
- 只凭“冲墓”就说开库发财。
- 只凭“财在主位”就说钱归本人。
- 只凭“食伤+财”就说食伤生财做成。
- 只凭神煞改变第一主线。
- 把书中某一个案例的职业直接推广成通用规则。
- 把教学中的财富金额/官阶映射当作现代统计概率。
