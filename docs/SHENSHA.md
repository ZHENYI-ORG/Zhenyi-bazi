# 神煞规则系统说明

真一八字排盘把神煞实现为**结构化规则匹配系统**，而不是在前端写死神煞名称。

## 当前规模

当前 `src/data/shensha-rules.json`：

- 78 条结构化基础规则
- 59 类神煞名称
- 340 个规则目标标签映射
- 结合年 / 月 / 日 / 时 / 大运 / 流年等目标展开后形成 300+ 匹配路径
- 完整计算路径覆盖主命局、12 步大运、每步 10 个流年

因此 README 使用“**200+ 神煞判定项 / 场景**”描述系统覆盖能力，而不是声称存在 200 个不同名称的神煞。

## 匹配模型

匹配器支持多种规则形态，包括：

- 天干 → 地支
- 地支 → 地支
- 地支 → 天干
- 干支精确匹配
- 干支 → 地支
- 多天干组合
- 五行 → 地支

规则可以限定来源柱、目标柱和性别范围，并统一输出命中来源、目标位置、目标干支等结构化信息。

## 为什么使用结构化规则

结构化的价值在于：

1. 规则来源和口径可以被检查；
2. 可以针对某条神煞单独写回归测试；
3. 可以扩展到大运和流年，而不是只计算原局；
4. 可以区分“规则不同”与“代码错误”；
5. 后续新增神煞不需要重写整个排盘核心。

## 关于门派差异

神煞在不同古籍、不同门派中的取法并不完全一致。同名神煞也可能存在年干取、日干取、年支取、日支取等不同口径。

因此本项目更强调“**规则明确、可复核、可修订**”，而不是把任意一套口径宣传成唯一标准。

如果你希望修正规则，请在 Issue / PR 中同时提供具体规则、使用的主位 / 客位、理论来源或可复核案例。
